## 二、背景与目标（是否需要后台的论证）

### 2.1 为什么需要

| 诉求 | 双端 App 能否承载 | 后台承接方式 |
|------|-------------------|--------------|
| 内置题库批量上架/下架/版本管理（App PRD FR-05） | 否：B 端批量操作（千题级导入、批量改分类）不适合手机端 | 题库运营模块 |
| 家长上传题目的人工复核（App PRD FR-06 机审拦截后需人工裁决） | 否：审核属内部职能，且涉隐私数据不能暴露给外部用户 | 内容审核工单 |
| 退款审批、对账差异处理、资损告警处置（App PRD FR-28 资金三件套） | 否：财务处置需要批量查询、导出、双人复核 | 订单与资金模块 |
| 学生作弊申诉、绕过事件申诉的客服裁决（App PRD E-06） | 否：需要全局上下文与操作留痕 | 客服工单模块 |
| 核心指标看板与运营决策（App PRD 2.2 五项指标） | 否：管理层需要跨维度报表与导出 | 数据看板模块 |
| 价格调整、敏感词库、奖励活动等全局配置 | 否：改配置不能靠发版 | 系统配置模块 |

**结论：需要。** 后台不是「锦上添花」，而是 App PRD 中 5 项合规/资金/运营硬要求的唯一可落地入口；无后台则内容合规与资金处置流程无法闭环。

### 2.2 成功指标（口径见 8.3）

| 指标 | 定义与口径 | 目标值（上线后 2 个月，估算） |
|------|-----------|------------------------------|
| 审核时效 | 家长上传题目从提交到人工裁决完成的 P95 时长 | ≤ 4 小时 |
| 退款处理时效 | 退款申请从提交到处理完成的 P95 时长 | ≤ 24 小时 |
| 申诉处理时效 | 学生/家长申诉从提交到裁决的 P95 时长 | ≤ 48 小时 |
| 对账差异闭环率 | T+1 对账差异订单在 3 个工作日内处理完毕的比例 | 100% |
| 后台事故率 | 因后台误操作引发的线上问题（P1/P2）次数 | 0 次/月 |

## 三、名词与术语定义

| 术语 | 定义 |
|------|------|
| RBAC | 基于角色的访问控制：账号 → 角色 → 权限点 |
| 双人复核 | 敏感操作（退款、封禁、批量删除）需第二人审批后生效的机制 |
| 审计日志 | 后台所有写操作的不可篡改记录（操作人/时间/改前值/改后值/IP） |
| 审核工单 | 家长上传题目机审后需人工裁决的任务单元 |
| 对账差异单 | 渠道账单与我方订单不一致时生成的待处理工单 |
| 灰度开关 | 控制某功能对线上用户是否可见的服务端配置项 |

## 四、需求范围

### 4.1 本期包含（MVP 6 模块）

1. 账号与权限管理（RBAC + 双因素 + 审计日志）。
2. 用户管理（家长/学生查询、状态管理、设备解绑、注销处理）。

## 五、方案对比与选型说明

### 5.1 候选方案

| 维度 | 方案 A：自研 Web 后台（React/Vue + 现成组件库） | 方案 B：基于开源 Admin 框架二次开发 | 方案 C：无后台，运营靠数据库脚本 |
|------|------------------------------------------|--------------------------------------|----------------------------------|
| 实现成本 | 中高 | 低（脚手架成熟） | 零开发 |
| 审计与安全 | 完全可控（RBAC/审计/双因素自建） | 可控（框架自带 RBAC，审计需补） | 不可控：无权限、无审计、误操作直连生产库 |
| 合规支撑 | 人工复核/退款审批/对账流程可产品化 | 同左 | 无法支撑资金三件套与审核闭环 |
| 上线时间 | 慢（约 4 周） | 快（约 2 周） | 即时 |

### 5.2 推荐结论

**推荐方案 B**（成熟 Admin 框架二次开发 + 自建审计日志与双人复核），理由：后台的核心诉求是「安全可控的处置能力」而非独特交互，开源框架的 RBAC/表格/表单能力可直接复用；方案 C 直接违反资金三件套要求（无审计、无审批流），明确否决；方案 A 的自研增量收益低于工期代价。

**演进路径**：MVP 6 模块（B 方案）→ 二期补活动系统与审核规则引擎 → 触发条件：月订单量 > 5000 单（估算）或审核量 > 200 单/日。

## 七、功能需求（FR-W01 ~ FR-W18）

> 状态词约定同主 PRD；每条附 Given/When/Then 验收标准。

### 7.1 模块一：账号与权限（FR-W01 ~ FR-W03）

**FR-W01 账号管理**
管理员必须可以创建/停用后台账号；后台账号禁止自助注册；登录必须双因素验证（密码 + TOTP）；密码连续 5 次错误锁定 30 分钟。

- Given 管理员创建账号「审核员-01」并绑定 TOTP，When 该账号登录，Then 需密码 + 动态码双验证方可进入。

**FR-W02 RBAC 权限**
权限按 6.2 矩阵落地到按钮/接口级；越权访问返回 403 并记录告警；角色变更实时生效（≤1 分钟）。

- Given 客服角色访问「退款审批」接口，When 请求到达，Then 返回 403 并在安全告警中留痕。

**FR-W03 审计日志**
所有写操作（增删改、审批、配置变更）必须记录：操作人、时间、模块、对象、改前值、改后值、IP；日志只读、保留 ≥3 年（资金相关操作按财务规范执行）；支持按操作人/模块/时间检索导出。

- Given 财务审批一笔退款，When 操作完成，Then 审计日志含改前状态「退款中」与改后状态「已退款」。

### 7.2 模块二：用户管理（FR-W04 ~ FR-W06）

**FR-W04 用户查询**
必须支持按家长 ID/手机号（脱敏展示，完整号需「查看明文」权限 + 二次验证 + 留痕）查询；展示关联信息：学生列表、会员状态、订单概要、设备绑定、告警记录。

- Given 客服查询手机号尾号 1234 的家长，When 未申请明文权限，Then 展示 138****1234 及其关联学生与会员状态。

**FR-W05 用户状态处置**
管理员必须可以：封禁/解封家长账号（需填写原因，封禁后 App 端提示客服联系方式）、解除设备绑定（对应 App PRD E-05）、处理账号注销（触发 App PRD 11.3-4 的 15 个工作日删除流程）。封禁/解绑需双人复核。

- Given 客服核实某账号存在恶意刷广告行为，When 提交封禁并经第二人复核通过，Then 该家长 App 端登录被拒并展示申诉入口。

**FR-W06 数据导出**
用户数据导出必须脱敏（手机号/实名哈希化）、需管理员角色、记录审计日志；禁止导出学生作答明细原始数据（仅聚合）。

- Given 运营申请导出用户列表，When 导出完成，Then 文件中手机号全部脱敏且审计日志留痕。

### 7.3 模块三：会员与订单（FR-W07 ~ FR-W10）★资金处置

**FR-W07 订单查询**
必须支持按订单号/家长 ID/渠道/状态/时间多维筛选，字段含：金额（分）、支付渠道、渠道流水号、发货状态、退款记录、发货幂等键；支持导出（脱敏）。

- Given 财务按「已支付未发货」筛选，When 查询，Then 列出全部需补单订单，可一键触发补发货（对应 App PRD E-11）。

**FR-W08 退款审批**
退款申请（App PRD FR-28-7）进入后台审批流：客服初审 → 财务复核（双人复核）→ 调用渠道退款 → 会员权益折算终止 → 用户通知。全额免审例外：自动续费误扣 72 小时内申诉可由财务单人快速退（金额 ≤ ¥9 的月卡误扣场景，阈值可配置）。

- Given 家长申请年卡 7 天无理由退款，When 客服初审与财务复核均通过，Then 渠道原路退款，会员按剩余天数折算终止，双方端收到通知。

**FR-W09 对账差异处理**
T+1 对账生成的差异单（金额不符/状态不符/我方有渠道无/渠道有我方无）必须在后台列表呈现，支持：标记原因（掉单/重复/测试单/其他）、发起补单或冲正、关闭留痕；超 3 个工作日未处理自动升级告警至管理员。

- Given 对账发现 1 笔「渠道已支付、我方未发货」差异单，When 财务标记为掉单并补发货，Then 差异单关闭、审计留痕、用户会员即时延期。

**FR-W10 资损告警处置**
App PRD FR-28-5 四类资损告警实时进入后台告警中心（红点 + IM 推送），每条告警必须可跳转关联订单，处置结论必填（确认资损/误报/已修复）；资损确认单需附金额核算。

- Given 系统检出重复发货告警，When 财务确认资损 ¥9，Then 告警单关闭并关联冲正操作记录。

### 7.4 模块四：题库运营与内容审核（FR-W11 ~ FR-W14）

**FR-W11 内置题库管理**
内容运营必须可以：批量导入（Excel，同 App PRD FR-02 格式）、上架/下架（下架后 App 端不再出题，进行中任务不受影响）、按「科目×年级×难度」批量调整、查看各分类题量与被引用统计。

- Given 运营下架「数学·初三·L4」全部题目，When 学生端发起解锁，Then 出题引擎自动跳过该分类（题目池不足时按 E-03 提示）。

**FR-W12 家长题目人工复核**
家长上传题目机审通过后直接入库；机审拦截或命中灰词的进入人工复核工单，审核员必须可以查看题目全文并裁决：通过 / 驳回（驳回需选择违规类型，家长端收到原因）；时效要求 P95 ≤ 4 小时。

- Given 家长上传 20 题，其中 2 题命中灰词，When 审核员裁决 1 通过 1 驳回，Then App 端题库同步状态且家长可见驳回原因。

**FR-W13 违规题目应急下架**
对已入库题目（含内置与家长题）支持单题/批量紧急下架（一键操作，1 分钟内全端生效）；侵权投诉建立 48 小时内下架响应通道（承接 App PRD RK-03 应对措施）。

- Given 收到某内置题目侵权投诉，When 运营点击紧急下架，Then 60 秒内该题从出题池移除且记录留痕。

**FR-W14 敏感词库管理**
管理员必须可以维护机审敏感词/灰词库（增删改、批量导入），词库变更 5 分钟内生效至机审链路；全部变更留痕。

- Given 管理员新增灰词，When 家长上传含该词的题目，Then 进入人工复核工单。

### 7.5 模块五：客服工单（FR-W15 ~ FR-W16）

**FR-W15 申诉工单**
学生「作弊判废申诉」（App PRD E-06）与家长各类反馈统一建单，字段：工单类型、关联用户/任务/告警、处理时限（申诉 48h）；客服必须可以查看完整证据（作答记录快照、切屏次数、异常快答明细）后裁决：撤销判废（恢复本次任务有效性）/ 维持（告知理由）。

- Given 学生申诉「异常快答系网络卡顿误判」，When 客服核对作答耗时明细后撤销判废，Then 该任务恢复有效、学生获积分补偿（如适用）、家长端同步更正告警。

**FR-W16 工单流转与 SLA**
工单状态机：待处理 → 处理中 → 待用户确认 → 已关闭；超时未处理自动升级提醒；支持内部备注与转派。

- Given 工单创建 48 小时未裁决，When 到达时限，Then 系统升级提醒客服主管。

### 7.6 模块六：数据看板与系统配置（FR-W17 ~ FR-W18）

**FR-W17 数据看板**
必须覆盖：App PRD 2.2 全部五项指标（日更新，标注口径与数据延迟说明）、会员转化漏斗（试用 → 付费 → 续费）、收入日报（按套餐/渠道拆分）、广告免费天数使用分布、留存曲线；支持近 7/30/90 天切换与 CSV 导出。

- Given 管理层查看 11 月看板，When 切换「月卡 vs 年卡」拆分，Then 收入与转化数据按套餐正确拆分且与订单明细合计一致。

**FR-W18 系统配置**
管理员必须可以配置（全部变更留痕，价格类配置需双人复核）：三档套餐价格与文案、免费试用天数、广告换天数单日上限、敏感词库入口（跳 FR-W14）、灰度开关（新功能按用户比例放量）。

- Given 管理员将月卡价格从 ¥9 调整为 ¥12 并双人复核生效，When 用户端拉取价格，Then 新购/续费展示 ¥12，存量未到期会员不受影响（对应 App PRD FR-25）。

## 八、非功能需求、流程与数据

### 8.1 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 列表查询（10 万订单级）P95 ≤ 2s；导出 1 万行 ≤ 30s（异步任务） |
| 安全 | 内网/VPN 访问 + HTTPS；双因素登录；接口按 RBAC 鉴权；审计日志防篡改（append-only） |
| 可用性 | 与主服务同可用性目标（≥99.5%）；后台故障不影响 App 端核心解锁链路（读写隔离，后台慢查询不冲击线上库，报表走只读从库） |
| 兼容 | Chrome/Edge 最近两个大版本，最小分辨率 1366×768 |

### 8.2 关键流程与状态

- **退款审批流**：申请 → 客服初审 → 财务复核 → 渠道退款 → 权益折算 → 通知关闭（每步可驳回并留痕）。
- **审核工单状态机**：待分配 → 审核中 → 已通过/已驳回 →（申诉）重审；超时自动升级。
- **差异单状态机**：待处理 → 处理中 → 已关闭（补单/冲正/标记关闭），超 3 个工作日升级告警。

### 8.3 指标口径与数据来源

- 审核时效 = 人工裁决完成时间 − 工单创建时间（P95，自然小时）。
- 退款处理时效 = 渠道退款到账回执时间 − 申请提交时间（P95）。
- 对账差异闭环率 = 3 个工作日内关闭的差异单 ÷ 当期差异单总数。
- 看板指标与 App PRD 2.2 / 10.3 口径完全一致（同一数据服务，避免双口径）。

### 8.4 异常处理清单

| 编号 | 异常场景 | 处理方式 |
|------|----------|----------|
| WE-01 | 后台数据库连接耗尽 | 报表查询走只读从库 + 查询超时熔断，保障 App 主链路 |
| WE-02 | 退款调用渠道失败 | 订单停留「退款中」，自动重试 3 次后转人工差异单 |
| WE-03 | 双人复核第二人长期未响应 | 24 小时未复核自动提醒，48 小时升级管理员 |
| WE-04 | 审计日志写入失败 | 操作与日志写入同事务，失败则操作回滚（保证日志完整性优先） |
| WE-05 | 批量导入中途失败 | 事务按批次提交，失败批次可重传，不产生半成品数据 |
