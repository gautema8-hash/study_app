1. 背景与目标

当前平台题目数据分散于「平台内置题库」与「家长自建题库」中，家长无法按需获取成体系的题目内容，运营侧也缺少对优质题目内容进行组织、包装与分发的通道。

1.1 目标

  • 运营侧：提供独立 Web 管理端，支持将平台内置题目组织为「题库」（题包），经审核后上架至题库商店，并可打标签、管理上下架。
  • 家长侧：家长端 App 展示已上架题库，支持按需浏览、搜索、筛选，将所需题库添加（下载）到家庭题库，题目进入现有刷题/解锁任务链路。
  • 分配管理：家长可将已添加题库分配给自己的子女（student_profile），并随时收回或重新分配；确保家长与子女账号关联准确（profile 必须属于当前 family）。
  • 可控上架：题库内容录入 → 提交审核 → 审核通过上架的完整状态机，杜绝未审核内容到达家长端。
  • 可运营：商店列表展示下载量，支持按科目/年级/标签/关键词筛选，为运营决策提供数据。

1.2 名词约定

名词定义
题库（题包）一组平台内置题目（question，family_id IS NULL）组成的可上架商品，对应表 bank_store_item
添加 / 下载家长将题库加入家庭题库的动作；系统将题目复制为该家庭名下题目（source=2），此后随家庭题库参与出题
分配家长把已添加题库授权给某个子女档案（student_profile），对应表 family_bank_assign
标签运营在后台为题库打的运营标签（如「期末冲刺」「思维训练」），家长端可用于筛选

2. 角色与权限

角色端权限
OPS / REVIEWER / ADMINWeb 管理端题库录入、编辑、提交审核；REVIEWER 与 ADMIN 可执行审核裁决与打标签；ADMIN 可上下架
家长（scope=parent）家长端 App浏览商店、搜索筛选、查看详情、添加题库、管理「我的题库」、分配/回收子女
子女（student_profile）学生端本期不开放商店入口；仅消费被分配题库内的题目（复用现有出题链路）

鉴权沿用现有机制：管理端走 AdminAuthInterceptor（admin scope JWT，写操作按角色放行）；家长端沿用 TokenService.verify + scope=parent 校验。

3. 核心业务流程

3.1 题库上架状态机

0 草稿→ 提交 1 待审核→ 审核通过 2 已上架→ 下架 3 已下架→ 重新编辑提交 1 待审核
1 待审核→ 审核驳回 4 已驳回→ 编辑后重新提交 1 待审核
  • 仅 状态=2 已上架 的题库对家长端可见；下架不影响家庭已添加内容（已复制题目不受影响）。
  • 审核时校验：题包内题目均为内置题（source=1）、状态=1 上架、机审通过（review_status=0），且题目数 ≥ 1。
  • 驳回必须填写驳回原因（≤200 字），展示给运营。
  • 状态迁移全部落审计字段（reviewed_by / reviewed_at / published_at），便于追溯。

3.2 家长添加与分配流程

浏览商店→ 搜索/筛选→ 查看详情→ 添加到我的题库→ 分配给子女
  • 添加（幂等）：唯一键 (family_id, store_item_id) 防重；重复添加返回成功但不重复扣量。仅首次添加使 download_count + 1。
  • 题目复制：添加时将题包内题目复制为家庭题目（family_id=当前家庭，source=2，status=1，review_status=0），并写入映射表，保证移除时可精准回收。
  • 分配（幂等）：唯一键 (store_item_id, profile_id)；已收回的分配可重新激活。分配前强校验 profile 归属当前 family，杜绝越权分配他人子女。
  • 移除：家长可移除已添加题库——复制题目进入回收站（status=3），分配关系作废，商店可重新添加（重新复制）。

4. 功能需求

4.1 Web 管理端（题库商店运营）

P0FR-S01 题库录入

运营填写题库名称（≤64字，必填）、简介（≤200字）、科目、年级，并从内置题目池多选题目（1~200 题）组成题包。题目选择器支持按科目/年级/关键词筛选。保存后为「草稿」。

P0FR-S02 题库编辑

仅草稿(0)、已驳回(4)、已下架(3) 状态可编辑基础信息与题目清单；已上架(2) 不可编辑，需先下架。

P0FR-S03 提交审核

草稿/驳回/下架 → 待审核。提交时服务端复验题目清单合法性（题目存在、内置、上架、机审通过）。

P0FR-S04 审核裁决（REVIEWER/ADMIN）

待审核列表逐条裁决：通过 → 立即上架并记录 published_at；驳回 → 必填原因。审核页可预览题包内全部题目。

P0FR-S05 上下架

已上架可下架（家长端即时不可见）；已下架可重新编辑后提交审核再次上架。

P0FR-S06 标签管理

标签 CRUD（名称 ≤16 字唯一，颜色可选）；每个题库可挂 0~5 个标签；支持批量打/改标签。家长端按标签筛选。

P0FR-S07 题库列表与筛选

列表列：ID、名称、科目/年级、题量、标签、下载量、状态、审核信息、时间。筛选：状态/科目/年级/关键词（名称模糊）。分页 size≤100。

4.2 家长端 App（题库商店）

P0FR-S08 商店浏览与筛选

展示已上架题库卡片：名称、简介、科目/年级、题量、标签、下载量；支持关键词搜索（名称/简介模糊）+ 科目/年级/标签筛选 + 分页（下拉加载）。已添加的题库显示「已添加」标识。

P0FR-S09 题库详情

展示题包全部题目（题干、选项、答案、解析），供家长添加前预览。

P0FR-S10 添加题库

一键添加：复制题目入家庭题库（幂等），首次添加下载量 +1，给出成功反馈。仅 scope=parent 可操作（FR-10 沿用）。

P0FR-S11 我的题库与分配管理

「我的题库」Tab 展示已添加题库及其当前分配对象；支持勾选一个或多个子女完成分配/取消分配；子女列表实时来自 student_profile；非本家庭子女返回 403。

P1FR-S12 移除题库

从我的题库移除：复制题目进入回收站、分配关系作废；下载量不回退（商店下载量为累计口径）。

5. 数据模型（sql/V1.5__bank_store.sql）

表用途关键字段 / 约束
bank_store_item题库（题包商品）title/description/subject/grade；status 0草稿 1待审核 2已上架 3已下架 4驳回；question_count 冗余题量；download_count 累计下载量；审核字段 reviewed_by/reviewed_at/review_reason；uk_code 业务编码唯一
bank_store_question题包↔题目关联uk_item_question(store_item_id, question_id)；sort_no 排序
bank_store_tag运营标签uk_name 名称唯一；color 展示色
bank_store_item_tag题包↔标签uk(store_item_id, tag_id)；单个题包 ≤5 标签（应用层校验）
family_bank_store家长添加记录uk(family_id, store_item_id) 幂等去重；added_at
family_bank_store_question添加时题目复制映射family_bank_id → 复制生成的 question_id，支撑移除回收
family_bank_assign家长→子女分配uk(store_item_id, profile_id) 幂等；status 1已分配 0已收回；强校验 profile.family_id = 当前 family
兼容性说明：本期不改 question 表结构，题目复制复用现有字段（source=2 家长自建语义），对出题链路零侵入。

6. 前后端接口契约

统一响应包装 {code:0, msg:"ok", data:{…}}；业务失败以 HTTP 4xx + msg 说明（沿用现有约定）。分页参数 page≥1、size≤100；列表返回 {total, page, list}。

方法路径说明关键参数 / 幂等

6.3 错误模型与边界（契约承诺）

场景HTTPmsg 示例
缺少/非法 token、scope≠parent401 / 403「缺少 token」「仅家长可访问」
参数非法（年级/科目/标签数>5/题目数>200 等）400「标签最多5个」「题目数须为1-200」
状态机非法迁移（如草稿直接下架）400「当前状态不允许该操作」
分配非本家庭子女403「子女不属于当前家庭」
资源不存在400「题库不存在或已下架」
  • 幂等：添加与分配均为唯一键幂等；客户端可安全重试，无重复副作用。
  • 越界请求：size>100 截断为 100；page<1 视为 1；未知筛选值按空集返回，不报错。
  • 演进：响应字段只增不改；后续若引入付费题库，将新增 price/order 字段与独立下单接口，不破坏现有契约。

7. 页面结构

7.1 Web 管理端（web-frontend，菜单「题库商店」/store）

  • 列表区：筛选（状态/科目/年级/关键词）+ Table（名称、科目/年级、题量、标签、下载量、状态、审核信息、操作）。
  • 新建/编辑弹窗：基础信息表单 + 题目多选器（弹窗内二级 Table：科目/年级/关键词筛选、复选、已选计数）。
  • 操作列：编辑、提交审核、审核（通过/驳回原因弹窗）、下架、打标签（多选弹窗）。
  • 标签管理：页头「新建标签」入口。

7.2 家长端 App（app-frontend，家长首页新增「题库商店」入口 → /store）

  • Tab 商店：顶部搜索框 + 科目/年级/标签筛选 Chips；题库卡片列表（名称、简介、科目/年级/题量、标签、下载量、「添加/已添加」按钮）；下拉刷新 + 上拉分页；点卡片进详情（BottomSheet 展示题目预览）。
  • Tab 我的题库：已添加题库卡片 + 当前分配对象；「分配子女」弹层（子女复选、保存）；「移除」二次确认。

8. 非功能需求

维度要求
性能商店列表 P95 ≤ 300ms；列表查询命中 idx_status(subject,grade) 组合索引；下载量为列上原子自增，无行锁长事务
一致性添加 = 题目复制 + 映射写入在同一事务；下载量自增在去重提交成功后执行，允许最终一致（计数口径为累计）
安全家长端全量 parent scope 校验；分配强校验家庭归属；管理端写操作 RBAC（REVIEWER/ADMIN）；题目答案仅对家长下发，不进学生端离线包
可追溯上架/下架/审核记录操作人与时间；后续可接入 audit_log 哈希链
兼容不改 question 表结构与现有接口；所有新接口为新增资源，零破坏性变更

9. 验收标准（关键用例）

  1. 运营创建题包→提交→审核通过后，家长端商店可见；驳回时家长端不可见且后台可见原因。
  2. 未上架（草稿/待审核/下架/驳回）题库在家长端任何接口均不可见、不可添加。
  3. 家长重复点击「添加」仅产生一次题目复制与一次下载量累加（幂等验证）。
  4. 添加后题目出现在家庭题库列表，可被现有解锁任务出题链路选中。
  5. 家长 A 无法给家长 B 的子女分配（403）；收回后可重新分配。
  6. 移除题库后家庭题目进入回收站，分配关系清空；可重新添加。
  7. 下载量随首次添加单调递增；筛选（科目/年级/标签/关键词）与分页边界（size>100 截断）行为正确。
