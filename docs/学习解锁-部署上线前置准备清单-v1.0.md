# 「学习解锁」部署上线前置准备清单

> 版本：v1.0 ｜ 日期：2026-11-04
> 定位：从「代码开发完成」到「正式上线」之间的全部前置事项，按启动优先级排序。**每项均标注前置耗时，长周期项（备案/签约）必须在开发期并行启动，不能等开发完成再做。**
> 依据：App PRD v1.4 · Web 后台 PRD v1.0 · 评审报告 v1.0 · 两份技术架构文档
> 合规声明：本方案为上线准备参考，具体实施请结合公司合规与法务要求确认。

---

## 0. 使用说明

- 【P0】= 不完成无法上线（阻塞级）；【P1】= 影响体验与运营，上线前必须有；【P2】= 可上线后 2 周内补齐；
- 「耗时」为办理/审批周期的经验估算（标注估算），请按最坏情况倒排；
- 建议每周五对照本清单盘点一次状态（✅ 完成 / 🔄 进行中 / ⬜ 未启动）。

## 7. 上线顺序建议（分四步走，规避依赖死锁）

```
第 1 步：商店上架「免费版」（广告免费通道 + 家长自建题库 + 3 天试用）
        ← 规避：广告平台要求已上架（2.5）、商店审核周期不可控
第 2 步：内置题库授权到位 → 灰度开放内置题库
第 3 步：Android 开放支付（¥9/99/199/299 四档 + 自动续费）→ Web 后台资金模块全量
第 4 步：iOS 支付按 IAP 专项结论开放（或维持免费版 + 官网引导）
每步之间观察 ≥1 周核心指标（解锁完成率/崩溃率/绕过率）再推进。
```
