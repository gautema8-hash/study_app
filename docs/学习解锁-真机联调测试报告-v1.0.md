## 一、联调方案与排障

| 项 | 结论 |
|------|------|
| 连接方式 | **`adb reverse tcp:8080 tcp:8080`（USB 端口转发）**：手机访问 `127.0.0.1:8080` 直达 PC 后端，绕过 Windows 防火墙（添加入站规则需管理员失败、手机 ping PC 100% 丢包） |
| 构建参数 | `flutter build apk --debug --dart-define=API_BASE=http://127.0.0.1:8080` |
| 关键修复 1 | Android 9+ 默认禁止明文 HTTP → manifest 增加 `android:usesCleartextTraffic="true"`（否则真机首次请求 `code=null`） |
| 关键修复 2 | `api.dart` 只捕获 ApiException → 网络层异常被吞；改为捕获全部异常并透出真实原因（连接拒绝/响应非 JSON/HTTP 状态） |
| 已知边界 | 本次 USB 转发方案要求手机保持 USB 连接；改 WiFi 直连需 `API_BASE=http://192.168.31.197:8080` 且 PC 放行 8080 入站 |
