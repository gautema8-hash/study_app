## 二、背景与目标

### 2.1 背景与要解决的问题

- 中小学生手机使用与学习的时间冲突是家庭高频矛盾：学生拿起手机后先娱乐、后学习甚至不学习。
- 现有手段（家长没收、系统屏幕时间）是「堵」而非「疏」，容易引发对抗，且无法把「使用手机」与「完成学习」正向绑定。
- 本产品把手机使用权设计为「学习成果的奖励」：学生答够分数才能解锁手机，实现「先学习、后娱乐」的行为引导。

### 2.2 成功指标（口径见第十节 10.3）

| 指标 | 定义与口径 | 目标值（上线后 3 个月，估算） |
|------|-----------|------------------------------|
| 解锁完成率 | 完成答题并 ≥ 门槛分数的解锁发起次数 ÷ 总解锁发起次数 | ≥ 85% |
| 周连续打卡率 | 当周连续 ≥5 天完成解锁学习的学生数 ÷ 活跃学生数 | ≥ 40% |
| 家长周活跃率 | 当周至少编辑/查看 1 次题库或报告的家长 ÷ 注册家长 | ≥ 60% |
| 答题正确率提升 | 学生当前月各科目平均正确率 − 首月基线正确率 | ≥ 5 个百分点 |
| 绕过事件发生率 | 被防绕过机制拦截或上报的异常解锁 ÷ 总解锁次数 | ≤ 1% |

## 三、名词与术语定义

| 术语 | 定义 |
|------|------|
| 解锁任务 | 学生发起解锁后收到的一组题目（含时长、数量、门槛分数配置），是解锁的必要条件 |
| 门槛分数 | DIY 配置中设定的最低得分（0~100 分），达到方可解锁 |
| 题目难度 | 分为 L1~L5 五级，由家长标记或系统按正确率自动校准 |
| 能力值 | 系统按学生分科目历史作答正确率与难度加权计算的估计水平（0~100，估算口径见 7.2） |
| 解锁会话 | 一次「发起解锁 → 答题 → 判分 → 开放使用 → 会话结束」的完整状态周期 |
| 会话有效期 | 解锁成功后手机可正常使用的时长，到期自动重新进入锁定态（家长可配） |
| 防绕过校验 | 防止学生不答题、篡改判分、卸载 App 等方式绕过规则的技术机制集合 |
| 家庭账号 | 以家长为主体的账号（v1.2：微信授权或手机号登录创建），名下可挂一个或多个学生档案；登录后按身份选择进入家长端/孩子端 |
| 监护人授权 | 家长（监护人）为学生账号完成注册并授权采集必要数据的过程，合规前提 |

## 四、需求范围

### 4.1 本期包含

1. 学生端：锁定/答题/解锁/使用倒计时全流程，激励中心（积分、成就、打卡）。
2. 家长端：题库管理（上传/编辑/删除，按科目·年级·难度分类）、DIY 配置（答题时长、题目数量、分数门槛、会话有效期、免锁时段）、学习报告。
3. 自动匹配引擎：按年级 + 能力值出题，支持薄弱科目加权。
4. 防绕过校验机制：服务端判分、卸载防护、异常上报、家长端告警。
5. 激励机制：积分、勋章成就、连续打卡奖励、家长自定义奖励兑换。
6. 会员与商业化（v1.1 新增）：家长端 VIP 会员（月卡/年卡/永久）、新用户 3 天免费试用、激励视频换免费天数。
7. 账号与登录（v1.2 新增）：微信授权登录、登录后身份选择（家长/孩子）、同一账号多设备跨平台绑定（Android/iOS）。

### 4.2 本期不包含（明确不做）

| 不做项 | 说明 | 后续路径 |
|--------|------|----------|
| 学生端任何付费/广告入口 | 未成年人禁止成为付费主体与广告受众；所有购买与广告行为仅限家长端执行 | 长期原则，不随版本变化 |
| 多设备/平板/iPad 管控（v1.3 明确） | 管控对象 = 每个学生档案绑定的 1 台手机；家庭其他设备（iPad/电脑/第二部手机）不在本期管控范围；家长端报告页必须明示该边界以防预期落差 | 二期评估扩展绑定平板 |
| 社交功能（好友/排行公开） | 未成年人社交合规风险高，仅保留学生本人可见的匿名段位 | 暂不规划 |
| iOS 设备级强管控 | 受系统 API 限制无法强制锁定全机；iOS 孩子端提供「提醒级管控」替代（答题解锁 + 锁定页常驻 + 屏幕使用时间引导） | Android 管控能力对齐项，长期评估 |
| 拍照搜题/AI 讲解 | AI 内容合规与版权风险 | v2.x 评估 |
| 学生间题库共享 | 版权与内容审核成本 | 不做 |

## 五、方案对比与选型说明

### 5.1 候选方案

| 维度 | 方案 A：设备级强管控（Device Admin + 服务端判分） | 方案 B：应用级提醒管控（仅自家 App 内提醒，无系统级锁定） |
|------|--------------------------------------------------|----------------------------------------------------------|
| 实现成本 | 中高（需设备管理员权限适配各厂商 ROM） | 低 |
| 防绕过强度 | 强：卸载需家长密码，锁定态覆盖全机 | 弱：学生可无视提醒直接使用其他 App |
| 用户体验 | 解锁流程有仪式感，规则可信 | 规则形同虚设，学生端信任度低 |
| 风险 | 厂商 ROM 兼容性（华为/小米/OPPO/vivo 后台杀进程差异）；权限引导失败则核心功能失效 | 产品核心价值不成立 |
| 上线时间 | 慢（需兼容性专项测试） | 快 |

### 5.2 推荐结论

**推荐方案 A**，理由：产品的核心价值主张是「规则有效执行」，方案 B 无法保证校验有效性，属于伪需求实现；方案 A 的 ROM 兼容风险通过「兼容性白名单 + 降级模式」（见 7.3.6 与第十二节）缓解，不构成不可控风险。

**演进路径**：本期双平台同发（Android 强管控 / iOS 提醒级管控）→ 二期持续跟进 iOS 系统能力与审核政策，评估提升 iOS 管控强度 → 触发条件：Apple 开放相应系统能力或审核政策允许同类功能完整上架。

### 5.3 商业化模式选型说明（v1.1 补充）

| 维度 | 纯订阅（月/年） | 纯买断（永久） | 三档混合 + 广告免费通道（推荐，已采纳） |
|------|----------------|----------------|----------------------------------------|
| 收入结构 | 持续、可预测 | 一次性 | 订阅为主 + 买断收割高意愿用户 + 广告兜底转化 |
| 用户门槛 | 中（对长期价值存疑者易流失） | 高（首次决策重） | 低（3 天试用 + 看视频可 0 成本续用） |
| 风险 | 自动续费投诉 | 无持续收入、长期服务成本倒挂 | 广告体验与合规管理成本 |

**推荐结论**：采纳三档混合（月卡 ¥9 / 年卡 ¥99 / 永久 ¥199）——年卡对月卡用户形成「年付省 8%（9×12=108 → 99）」的升档牵引，永久卡锚定价格上限（约 22 个月月卡金额回本，估算）；「看 1 条激励视频换 1 天」承担拉新留存与广告变现双重职能。v1.4 新增 **SVIP 永久卡 ¥299** 作为最高档锚点：面向多孩/多设备家庭（3 台学生手机 + 1 台父母手机），与 VIP ¥199 形成 ¥100 的升档差，同时为多孩方案（G-05）提供商业载体。

## 六、用户角色与使用场景

### 6.1 用户角色

| 角色 | 说明 | 核心目标 | 能力水平 |
|------|------|----------|----------|
| 家长（监护人） | 家庭账号主体，微信授权或手机号登录，需实名核验；管理题库与规则，查看报告；可在 Android/iPhone 上使用 | 让孩子先学习后娱乐，掌握学习情况 | 熟练智能手机用户 |
| 学生（被监护人） | 6~18 岁，登录后选择「孩子」身份并绑定设备；发起解锁、答题、使用手机、查看激励；Android 强管控 / iOS 提醒级管控 | 快速通过解锁，获得成就与奖励 | 按年龄分级设计 UI（A-05） |

### 6.2 核心使用场景

**场景 1：日常解锁（主流程）**
学生课余想玩手机 → 点击「解锁」→ 系统按其年级与能力值出题（如 10 题限时 5 分钟）→ 提交后服务端判分 → ≥80 分立即解锁，手机可正常使用会话有效期（如 60 分钟）→ 到期自动回到锁定态。

**场景 2：家长配置**
晚上家长收到孩子数学正确率下降的报告 → 打开家长端 → 筛选「数学 · 初二 · L3」题目，追加 5 道错题同源题 → 将数学出题权重调高 → 保存次日生效。

**场景 3：答题失败**
学生得分 65 < 门槛 80 → 展示得分与错题解析 → 提供两个选择：再挑战一次（换题）或稍后再试 → 每日挑战次数上限 3 次（防机械刷题，家长可调）。

**场景 4：绕过尝试（异常流程）**
学生尝试强制停止/卸载 App → 触发设备管理防护，卸载需要家长密码 → 连续 3 次异常操作上报家长端告警。

**场景 5：免锁时段**
家庭约定周五晚为自由使用时间 → 家长预先配置 19:00–21:00 免锁 → 学生在时段内无需答题直接使用（家长保留随时收回权限的能力）。

## 七、功能需求

> 状态词约定：必须（shall）/ 应该（should）/ 可以（may）/ 禁止（must not）。
> 每条需求附 Given/When/Then 验收标准。

### 7.1 模块一：家长端题库管理（FR-01 ~ FR-06）

**FR-01 题目创建与编辑**（来源：用户需求 1）
家长必须可以创建题目，字段包括：题干（文本）、题型（单选/多选/判断/填空）、选项或答案、解析、科目（语文/数学/英语/物理/化学/生物/历史/地理/政治/其他）、年级（小学 1~6 年级 / 初中 1~3 年级 / 高中 1~3 年级）、难度（L1~L5）、分值。编辑已录题目必须保留修改记录。

- Given 家长在题库管理页，When 点击「新建题目」并完整填写必填字段后保存，Then 题目出现在题库列表且分类筛选可命中。
- Given 家长编辑一道已有题目，When 保存修改，Then 题目更新且修改记录（改前值/改后值/时间）可在操作日志查看。

**FR-02 题目批量导入**
家长应该可以通过 Excel 模板批量导入题目（每批 ≤500 题）；导入时必须逐行校验（必填项、答案格式、科目年级枚举值），校验失败的行单独列出并可下载错误清单，合格行正常入库。

- Given 家长上传含 100 行的 Excel，其中 3 行答案格式错误，When 导入完成，Then 97 行入库，3 行错误明细可下载且不影响合格行。

**FR-03 分类与筛选**
题库必须支持按「科目 × 年级 × 难度」三维筛选，且筛选支持组合与清空；列表应显示题目总数与各难度分布。

- Given 题库含多科目题目，When 家长筛选「数学 + 初二 + L3」，Then 列表仅显示同时满足三个条件的题目，计数准确。

**FR-04 题目删除与回收站**
删除题目必须进入回收站（保留 30 天），期间可以（may）恢复；被解锁任务引用中的题目删除后，历史作答记录中的题目快照必须保留（不影响历史报告）。

- Given 家长删除一道本周已被答过的题目，When 进入回收站查看，Then 可恢复；学生历史报告中该题记录完整保留。

**FR-05 平台内置题库（依赖 D-01，阻塞级）**
平台应该提供按科目·年级·难度组织的内置基础题库（首期每「科目×年级」≥200 题，估算），家长可以直接启用/停用内置题库的组合；内置题目禁止（must not）含有版权争议内容（内容来源需取得授权）。

- Given 家长未上传任何自建题目，When 学生发起解锁，Then 系统从已启用年级匹配的内置题库出题，解锁流程不中断。

**FR-06 题目内容合规**
家长上传的题干、选项、解析必须经过内容安全校验（接入内容审核服务，依赖 D-02）；含违禁、广告、超纲敏感内容的题目禁止入库并提示原因。

- Given 家长上传含广告链接的题干，When 保存，Then 系统拒绝入库并明确提示违规类型。

### 7.2 模块二：智能匹配与 DIY 配置（FR-07 ~ FR-11）

**FR-07 自动出题匹配**
系统必须按以下优先级出题：① 目标年级匹配 → ② 按各科目配置权重抽取科目 → ③ 科目内按能力值选难度（能力值区间 ±1 级为主，占比 ≥70%）→ ④ 随机抽取避免近 7 天重复（同题 7 天内禁止重复出现）。
**能力值口径**：能力值 = 该科目近 30 天作答的「难度加权正确率 ×100」，权重 = 难度系数（L1=0.6, L2=0.8, L3=1.0, L4=1.2, L5=1.4）；作答不足 10 题的科目按年级默认中间值 L3 出题（估算口径，可由算法迭代）。

- Given 学生数学能力值 72（对应 L3 水平），When 发起解锁任务包含数学题，Then 数学题以 L2~L4 为主，且不出现其 7 天内答过的题目。
- Given 学生英语作答不足 10 题，When 出英语题，Then 难度以 L3 为基准。

**FR-08 DIY 配置项**
家长必须可以配置以下解锁任务参数（默认值给出，范围受限）：

| 配置项 | 默认值 | 允许范围 | 说明 |
|--------|--------|----------|------|
| 每次题目数量 | 10 题 | 5~30 题 | — |
| 答题总时长 | 10 分钟 | 3~30 分钟 | 到时未答完按已答题判分 |
| 分数门槛 | 80 分 | 60~100 分 | 低于门槛不解锁 |
| 会话有效期 | 60 分钟 | 15~240 分钟 | 到期重新锁定 |
| 每日挑战次数上限 | 3 次 | 1~10 次 | 防刷题 |
| 免锁时段 | 无 | 每日 ≤2 个时段 | 时段内直接可用 |
| 科目权重 | 均衡 | 每科目 0~5 档 | 0 为不出该科 |

配置修改应该支持「立即生效」与「次日生效」二选一，默认次日生效（避免打断学生正在进行的答题会话）。

- Given 家长把门槛从 80 改为 90 并选择次日生效，When 学生当天解锁，Then 当天仍按 80 分判定，次日按 90 分判定。

**FR-09 错题重练**
学生答错的题目应该（should）在 3 天后自动进入「错题重练」池，优先于新题出现（同次任务中错题重练占比 ≤30%），答对后移出池。

- Given 学生周一答错题 X，When 周四发起解锁，Then 任务中包含题 X（若错题池占比未超限）。

**FR-10 配置保护**
学生端禁止查看和修改家长的 DIY 配置；配置数据接口必须按角色鉴权（学生 token 无法读取门槛分数具体值，防止反向应试）。

- Given 学生账号调用配置查询接口，When 请求分数门槛字段，Then 接口返回脱敏数据（仅返回「已配置」状态），不返回具体数值。

**FR-11 预览试答**
家长应该可以（may）以学生视角「试答」当前配置生成的模拟任务，用于确认难度是否合适；试答记录不计入学生能力值与打卡。

- Given 家长点击「试答」，When 完成模拟任务，Then 生成试答得分但不影响学生任何数据。

### 7.3 模块三：解锁校验与防绕过（FR-12 ~ FR-18）★核心

**FR-12 解锁流程与判分**
学生发起解锁 → 出题 → 作答 → 提交 → 服务端判分 → 达标立即开放设备使用。判分必须且只能在服务端完成；客户端仅上报「题目 ID + 作答内容 + 作答耗时」，禁止在客户端落地答案明文与判分逻辑。

- Given 学生提交 10 题、得分 85、门槛 80，When 服务端判分完成，Then 2 秒内下发解锁指令，设备开放使用。
- Given 学生断网时答题，When 网络恢复，Then 本地加密暂存的作答记录自动上传补判（见 7.3.5 离线策略）。

**FR-13 防绕过机制（威胁模型 → 对策）**

| 编号 | 绕过手段 | 对策（必须实现） | 校验方式 |
|------|----------|------------------|----------|
| T-01 | 直接卸载 App | 引导激活设备管理器，卸载/停用需家长密码；未激活时每次开机强提醒激活 | 设置设备管理器后尝试卸载，需输入家长密码 |
| T-02 | 强制停止/禁用 App | 监听自身被杀事件，Guard 进程/JobScheduler 自动拉起；被强停记录异常事件 | 强停后 10 秒内 App 自动恢复前台锁定页 |
| T-03 | 篡改本地时间延长会话 | 会话到期时间以服务端下发的时间戳 + 服务端心跳校准为准，本地时间仅展示 | 拨快本地时间 30 分钟，会话仍按服务端时间锁定 |
| T-04 | 修改本地判分数据/抓包伪造提交 | 判分在服务端；作答请求带签名（时间戳+nonce+设备指纹）；同 nonce 禁止重复提交（幂等） | 重放同一提交请求，第二次被拒绝 |
| T-05 | 换设备/多开/虚拟机 | 设备绑定：学生账号激活时绑定设备指纹，更换设备需家长扫码确认；检测模拟器特征则拒绝答题 | 新设备登录学生账号，家长端收到扫码确认请求 |
| T-06 | 答题作弊（他人代答/搜题/超时切屏） | ① 答题页禁止截屏录屏、切出即暂停计时并记录次数；② 单题作答时长 < 2 秒且答对标记为「异常快答」，累计 ≥3 次本次判分作废并告警；③ 填空题答案命中常见搜题 App 剪贴板特征时提示家长 | 模拟 1 秒内连答 3 题，判分作废 + 家长告警 |
| T-07 | 免锁时段滥用改系统时区 | 免锁时段判定使用网络时间（NTP/服务端），与本地时间冲突 >5 分钟时以网络时间为准并告警 | 改时区后免锁时段判定不变 |
| T-08 | 在孩子设备上切换家长身份绕过管控 | 进入家长功能必须输入家长密码（FR-32）；密码错误 5 次锁定 30 分钟并告警家长主设备 | 孩子设备点「我是家长」，无密码仅可查看联系家长入口 |

**FR-14 异常上报与家长告警**
以下事件必须实时推送家长端并留存记录（≥90 天）：卸载尝试、强停恢复、异常快答判废、更换设备请求、时间篡改嫌疑、连续 3 天未发起解锁（可能已绕开管控）。

- Given 学生尝试卸载 App，When 防护触发，Then 家长端 1 分钟内收到推送「检测到卸载尝试（时间/设备）」。

**FR-15 家长紧急解锁**
家长必须可以远程立即解锁（无需答题），操作需要家长密码二次确认并记录；每日紧急解锁次数不做硬性限制但全部留痕。

- Given 家长输入正确密码点击「紧急解锁」，When 确认，Then 学生设备 10 秒内开放，且双方端均显示本次紧急解锁记录。

**FR-16 忘记密码与账号找回**
家长密码找回必须通过注册手机号验证码 + 实名信息核对；学生禁止（must not）通过任何自助路径重置家长密码或解除绑定。

- Given 家长忘记密码，When 走找回流程验证通过，Then 可重置密码且原设备绑定关系保留。

**FR-17 锁定态基础可用性**
锁定态下必须保留：接打电话（系统层不受限）、紧急呼叫、家长端电话/消息直达入口。App 锁定禁止阻断 110/120/119 等紧急能力（安全底线，不可妥协）。

- Given 设备处于锁定态，When 学生拨打紧急电话，Then 呼叫正常发起，不受任何限制。

**FR-18 降级模式**
设备管理器权限被取消或 ROM 不兼容时，App 应自动进入降级模式：无法强制全机锁定，改为「家长端实时告警 + 锁定页常驻通知」，并引导家长重新授权；降级状态必须在家长端显著标识。

- Given ROM 兼容失败，When 学生端启动，Then 进入降级模式，家长端首页显示「管控强度：提醒级（未完全生效）」黄色标识。

### 7.4 模块四：激励机制（FR-19 ~ FR-23）

**FR-19 积分体系**
积分获取口径：每答对 1 题 = 10 分 × 难度系数；一次性达标奖励 = 任务门槛差额奖励（如超门槛 15 分额外 +30）；单日获取上限 500 分（防刷）。积分消费：兑换家长自定义奖励（如「周末多 30 分钟屏幕时间」「实体奖品」，由家长在奖励商城上架并标注所需积分）。

- Given 学生答对 8 道 L3 题并超门槛 15 分，When 判分完成，Then 到账积分 = 8×10×1.0 + 30 = 110 分，记录明细可查。
- Given 学生兑换「周末多 30 分钟」，When 家长确认兑换（需家长确认的奖励类型），Then 奖励在指定会话自动生效。

**FR-20 成就勋章**
勋章示例（首批 ≥12 枚）：「首次通关」「连续打卡 7/30/100 天」「单次满分」「数学小达人（单科正确率 ≥90%）」「周末自律官」等。勋章获得时全屏轻庆祝动效（≤3 秒，禁止诱导性弹窗）。

- Given 学生达成「连续打卡 7 天」，When 当次解锁判分达标，Then 结算页展示勋章动效，勋章墙同步点亮。

**FR-21 连续打卡**
口径：自然日内完成 ≥1 次达标解锁任务即记 1 次打卡。连续打卡奖励：7 天 +200 积分、30 天 +1000 积分 + 专属勋章；断签不清零历史积分，但连续计数归零；提供每月 1 张「补签卡」（仅可补昨天的缺卡）。

- Given 学生连续 6 天打卡后第 7 天未达标，When 第 8 天达标，Then 连续计数从 1 重新开始，可用补签卡恢复为 8（若补签卡有剩余）。

**FR-22 学生端激励可见性**
学生端必须可以查看：当前积分、积分明细、勋章墙、打卡日历、下次可兑换奖励。禁止（must not）出现以下未成年人保护红线设计：限时倒计时诱导、连续充值/抽奖机制、社交攀比排行（仅本人可见进度）。

- Given 学生进入激励中心，When 查看任意页面，Then 无抽奖/概率性奖励入口，排行榜仅显示学生自己的历史曲线。

**FR-23 激励与解锁的正向绑定**
会话有效期应该（should）支持「学习奖励时长」叠加：家长可开启「每完成 1 次满分任务，当日会话有效期 +15 分钟（上限 +60）」，让学习表现直接兑换使用时长。

- Given 学生完成 3 次满分任务且家长开启该功能，When 当日再次解锁，Then 会话有效期为配置值 +45 分钟。

### 7.5 模块五：学习报告（FR-24）

**FR-24 家长端报告**
家长端应该提供：日/周/月维度的解锁次数、达标率、分科目正确率、错题 Top10、能力值变化曲线、绕过事件记录；报告数据与学生端一致，口径见第十节。

- Given 家长查看周报，When 切换科目筛选，Then 各图表按所选科目刷新且口径一致。

### 7.6 模块六：会员与商业化（v1.1 新增，FR-25 ~ FR-30）★资金类专项

> 本模块命中资金信号（支付/扣款/订阅/续费/退款），执行交易/资损专项 8 项清单；资金底线三件套（幂等 + 对账 + 资损监控）不可砍，任何排期压缩不得移除。

**FR-25 会员套餐与定价**

| 套餐 | 价格 | 有效期 | 续费方式 |

| 月卡 | ¥9 / 月 | 30 天 | 单次购买或自动续费（可选开通） |

新注册家长账号自动获得 3 天全功能试用（自注册时刻起按自然小时计），试用权益与 VIP 完全一致；试用剩余时长在家长端首页显著展示；试用到期前 24 小时推送一次提醒（仅 1 次，禁止频繁催费骚扰）。

- Given 家长注册成功，When 进入会员中心，Then 显示「试用剩余 X 天」且全功能可用。
- Given 试用到期且未购买，When 到期时刻到达，Then 按 FR-30 到期规则处理（管控暂停，不锁学生手机）。

**FR-27 激励视频换免费天数**
家长在家长端完整观看 1 条激励视频（15~30 秒）→ 获得 +1 天免费使用权（24 小时，自观看完成起算）；可以连续观看叠加，累计免费天数不设上限；单日奖励获取上限 10 天（防广告欺诈及广告平台政策约束，估算值，规则在奖励页对家长明示）。

约束（必须）：
1. 广告仅允许在家长端播放，学生端禁止出现任何广告位与广告渲染组件；
2. 免费天数发放必须以广告平台服务端回调（含签名校验）为准，客户端上报禁止作为发奖依据；
3. 同一回调 ID 幂等，不重复发奖。

- Given 家长连续 3 天每天观看 2 条激励视频且回调验签通过，When 天数结算，Then 累计免费时长正确叠加为 6 天。
- Given 学生端任意页面，When 全量遍历检查，Then 不存在广告入口。

**FR-28 支付、订单与对账（资金底线三件套落点）**

1. **支付渠道**：微信支付 + 支付宝（依赖 D-06）；流程 = 下单 → 唤起收银台 → 渠道回调 → 服务端发货（会员延期）。
2. **幂等**：发货幂等键 = 渠道订单号（out_trade_no），重复回调不重复延期；下单侧同一业务单号重复请求返回原订单。
3. **金额**：全部金额服务端计算、以「分」为单位整型存储；优惠/活动金额口径明确、明细可追溯；客户端传值禁止作为扣款依据。
4. **对账**：T+1 拉取渠道账单，逐单核对订单状态与金额；差异订单挂起并人工处理留痕。
5. **资损监控**：四类告警——重复发货、负金额/异常金额订单、状态回跳（退款后又发货）、对账差异超阈值（阈值 ≥1 笔即告警）。
6. **状态一致性**：订单状态机（9.5）+ 回调与主动查询双通道（支付后 5 分钟未收到回调则主动查单补单）。
7. **退款规则**：月卡/年卡 7 天内未使用可全额退款；自动续费误扣款 72 小时内申诉可全额退；永久卡支持 7 天无理由退款（以应用商店与应用内公示规则为准）；退款成功后会员权益按剩余天数折算终止。
8. **风控联动**：同账号高频下单、异常设备/异地支付触发风控拦截，拦截提示明确并支持申诉。

- Given 渠道回调丢失，When 支付后 5 分钟仍未回调，Then 服务端主动查单并补发货，订单状态与渠道一致。
- Given 家长申请月卡退款且未使用，When 审核通过退款成功，Then 会员立即按规则终止，且对账表中该订单标记为退款态。

**FR-29 自动续费（月卡/年卡可选开通）**
开通自动续费必须二次确认并明示扣费周期、金额与取消方式；每次扣费前 3 天推送提醒；家长可随时一键取消（取消路径 ≤2 步，禁止隐藏入口或设置取消障碍——应用商店审核硬要求）；取消后当前已付费周期内权益保留至到期。

- Given 家长开通月卡自动续费，When 下一周期扣费前 3 天，Then 收到扣费提醒推送；When 家长取消续费，Then 当期权益保留至第 30 天，之后按 FR-30 处理。

**FR-30 会员到期处理（安全底线，不可妥协）**
会员/试用/免费天数全部到期后，产品管控功能自动暂停：**学生端必须恢复正常自由使用手机，禁止因家长未续费而锁定学生手机**（未成年人权益优先于商业化）；家长端显著展示续费入口与到期提示；题库与学习数据保留 90 天，超期归档（续费后可恢复，不删除）。

- Given 会员到期时刻到达，When 状态机迁移到「已到期」，Then 学生设备自动解除管控（守护逻辑停用），家长端显示「会员已到期，管控已暂停」。

### 7.7 模块七：账号与登录（v1.2 新增，FR-31 ~ FR-34）

**FR-31 微信授权登录（家长身份）**
家长必须支持微信授权登录（App 微信 OAuth，获取 openid/unionid）；首次登录后必须补充手机号验证（用于告警与找回）并完成监护人实名核验后方可使用管控与支付功能；同时应该（should）保留「手机号 + 验证码」作为备用登录方式（微信授权失败/换手机场景）。

- Given 家长点击「微信登录」并完成授权，When 首次登录，Then 创建家庭账号并引导补充手机号与实名核验；第二次登录直接进入身份选择页。
- Given 微信授权被取消或失败，When 家长点击备用登录，Then 可用手机号验证码登录同一账号（unionid/openid 绑定关系保留）。

**FR-32 登录后身份选择**
单一 App，登录后必须进入身份选择页：「我是家长（管理）」/「我是孩子（被管控）」；选择「家长」需已通过实名核验（未核验则先引导核验）；选择「孩子」需选择/创建学生档案并绑定当前设备。身份选择结果记住上次选择（下次默认进入，可随时切换）。

- Given 家长在孩子设备上登录同一账号，When 点击「我是家长」，Then 必须输入家长密码方可进入家长功能（防绕过 T-08）。

**FR-33 设备绑定与跨平台**
同一账号可以在多台 Android/iPhone 设备登录；一个学生档案同时仅绑定一台管控设备（学生模式）；换绑需家长在新设备上扫码确认，旧设备自动退出学生模式（对应 E-05）。同时在线设备数按会员档位配额执行（见 FR-37 设备配额表），超出即被限制并提示；异地/新设备登录触发安全提醒。

- Given 孩子从 Android 换用 iPhone，When 家长在新 iPhone 扫码确认绑定，Then 学生档案迁移至 iPhone 并自动进入 iOS 提醒级管控（管控强度变化需家长端显著提示确认）。

**FR-34 登录态与安全**
登录态 token 有效期 ≤30 天（孩子设备可配置「离线宽限」≤72 小时，宽限期内管控规则继续生效，不因临时断网失效）；孩子设备上退出登录/卸载受 FR-13 防护约束；同一账号在两台设备同时以学生模式使用被禁止（互踢 + 告警）。

- Given 孩子设备断网 24 小时，When 期间发起解锁，Then 离线宽限内按缓存规则出题（缓存题包），恢复联网后补判分与上报。

**FR-35 家长密码体系（v1.3 补充）**
家长密码为独立于登录凭证的 6 位数字操作密码，用于：紧急解锁、远程收回、设备解绑、孩子设备上进入家长功能（T-08）、确认敏感兑换。必须：首次使用管控功能时强制设置；孩子设备禁止查看/修改该密码；找回仅可通过注册手机号验证码（对应 FR-16）或后台客服核验后重置；输入错误 5 次锁定 30 分钟并告警家长主设备。

- Given 家长首次进入规则配置页，When 未设置操作密码，Then 强制引导设置后方可继续。

**FR-36 离线题包安全（v1.3 补充）**
离线宽限期下发的缓存题包必须只含题干、选项与题目 ID，**禁止包含答案与解析明文**；作答记录加密暂存（AES-256，密钥服务端下发并绑定设备指纹），联网后由服务端判分——判分逻辑在任何场景下不得落地端上。

- Given 抓包或本地扫描离线题包文件，When 分析其内容，Then 不存在任何答案/解析字段。

**FR-37 设备配额与超出限制（v1.4 新增）**
同时在线设备数按会员档位配额管理（口径：近 72 小时内有活跃心跳的设备计入「在线」）：

| 会员档位 | 学生模式设备（同时在线） | 家长模式设备（同时在线） |
|----------|--------------------------|--------------------------|
| 免费/试用 | 1 台 | 2 台 |
| VIP（月卡/年卡/永久 ¥199） | 1 台 | 4 台 |
| SVIP（永久 ¥299） | **3 台** | **1 台** |

- 超出配额时的登录限制：新设备登录时必须提示「已达设备上限（N/N）」，并列出当前在线设备列表（设备类型/昵称/最近活跃时间）；家长可以选择「下线」某台在线设备（需家长密码，被下线设备 60 秒内退出登录态并收到通知），或在家长端完成升级后再登录新设备。
- 学生模式设备被下线后立即回到锁定态（不保留使用中会话）；fail-open 与紧急呼叫规则（E-15/FR-17）不受影响。
- 设备配额以服务端为准，客户端本地时间/卸载重装不能绕过（卸载重装视为新设备，占用配额；恢复出厂同样需重新绑定确认）。

- Given SVIP 家庭已有 3 台学生手机在线，When 第 4 台学生手机登录学生模式，Then 提示「已达学生设备上限 3/3」并列出在线设备，家长下线 1 台后新设备方可登录。
- Given VIP 家庭尝试在 5 台家长手机同时在线，When 第 5 台登录，Then 提示升级或下线一台。

**FR-38 SVIP 特权与授权（v1.4 新增）**
每个 SVIP 账号（以家庭账号为单位）可以为其家庭内的**一个学生档案**开通「SVIP 特权」：家长在会员中心指定特权学生档案（可随时更换，更换每月 ≤1 次）；SVIP 特权仅限本家庭账号与学生档案使用，禁止转赠或共享给其他家庭账号（风控校验，违规冻结特权并告警）。

SVIP 特权学生档案享受（首批权益，可调）：
1. 学生端专属「SVIP 星标」身份标识与 3 枚专属勋章（星标仅本人与家长可见，禁止公开攀比展示——未成年人保护红线）；
2. 每月额外 1 张补签卡（叠加 FR-21 基础权益）；
3. 积分获取 +10%（单日上限同步上浮至 550 分）；
4. 家长端 SVIP 专属客服通道（对应 G-07 客服体系）。

- Given 家长将 SVIP 特权指定给学生档案 A，When 学生 A 进入激励中心，Then 显示星标与专属勋章入口，积分获取按 1.1 倍计算；学生档案 B 不受影响。
- Given SVIP 账号尝试将特权绑定到其他家庭账号的学生，When 服务端校验家庭归属，Then 拒绝并记录风控事件。

### 7.8 平台管控强度说明（v1.2 补充）

| 平台 | 家长端 | 孩子端管控方式 |
|------|--------|----------------|
| Android | 全功能 | 强管控：设备管理器全机锁定（FR-13 全量生效） |
| iOS | 全功能 | 提醒级管控为底：答题在自家 App 内完成、解锁结果通过「屏幕使用时间引导 + 锁定页常驻通知 + 家长端告警」执行；**可选增强（iOS 16+，灰度验证）**：接入 FamilyControls/DeviceActivity/ManagedSettings（Screen Time API），经家长在设备上授权后对指定 App 实施 shield 遮罩，实现中等强度管控；最终强度以 Apple 审核结论为准。管控强度差异在购买前对家长明示 |

> 商业化合规提示（iOS）：会员属数字服务，App Store 审核通常要求使用 Apple IAP 内购（含平台抽成），微信/支付宝支付通道主要适用于 Android 端；iOS 端支付方案与上架策略需在 M3 前专项确认（见 RK-10）。

## 九、业务流程与状态流转

### 9.1 核心解锁流程

```
[锁定态] --学生点击解锁--> [出题] --题目下发--> [答题中]
   |                                              |
   |（免锁时段/家长紧急解锁 → 直接开放）            |--到时自动提交
   |                                              v
   |                                         [服务端判分]
   |                                              |
   |                          分数 ≥ 门槛        分数 < 门槛
   |                              |                  |
   |                              v                  v
   |                        [解锁成功]          [未达标页：得分/解析]
   |                              |                  |
   |                              v                  +--再挑战（次数未超）→ [答题中]
   |                        [使用中·倒计时]        +--次数已超 → [锁定态，次日再试]
   |                              |
   |                              +--会话到期/家长远程收回--> [锁定态]
```

### 9.2 解锁会话状态机

| 当前状态 | 触发事件 | 迁移到 | 允许的操作 |
|----------|----------|--------|-----------|
| 锁定 | 学生发起解锁 | 出题中 | 仅可发起解锁、紧急呼叫、联系家长 |
| 出题中 | 题目下发成功 / 失败 | 答题中 / 锁定（提示重试） | — |
| 答题中 | 提交 / 到时自动提交 / 切出 | 判分中 | 作答、暂停（切出自动暂停并计数） |
| 判分中 | 服务端判分完成 | 已解锁 / 未达标 | — |
| 未达标 | 再挑战（未超次数）/ 次数用尽 | 答题中 / 锁定 | 查看解析 |
| 已解锁（使用中） | 会话到期 / 家长收回 | 锁定 | 正常使用手机，可查看剩余时长 |
| 任意状态 | 紧急呼叫 | 临时开放呼叫（不改变状态） | 紧急通话 |

状态流转规则：状态单向流转，禁止「已解锁 → 答题中」回跳；判分以服务端落库结果为准，防重复提交（幂等键 = 学生 ID + 任务 ID + 时间戳）。

### 9.3 任务状态机（面向家长端配置与风控）

配置态 → 已生效 → （学生发起）进行中 → 已达标/未达标 → 已归档；异常任务（判废/作弊标记）单独标记并计入报告。

### 9.4 会员状态机（v1.1 新增）

| 当前状态 | 触发事件 | 迁移到 | 说明 |
|----------|----------|--------|------|
| 试用中 | 注册成功 | 试用中（3 天倒计时） | 试用权益 = VIP 全功能 |
| 试用中 | 试用到期且未购买 | 已到期 | 按 FR-30 处理，管控暂停 |
| 试用中 / 任意 | 支付成功 / 激励视频回调发奖 | 有效（VIP） | 有效期 = max(当前到期时间, 新到期时间) |
| 有效（VIP） | 一键取消自动续费 | 有效 → 到期转已到期 | 当期权益保留 |
| 有效（VIP） | 免费天数叠加 | 有效 | 到期时间顺延 |
| 已到期 | 续费支付成功 / 观看激励视频 | 有效（VIP） | 管控同时恢复 |
| 已到期 | 持续 90 天无动作 | 已归档 | 配置与数据归档，续费可恢复 |
| 任意状态 | 全额退款成功 | 已到期 | 按 FR-28 退款规则折算终止 |

> v1.4 说明：SVIP 状态迁移与上表一致（「有效（VIP）」含 SVIP）；档位只影响权益与设备配额（FR-25/37/38），不影响状态机。

### 9.5 支付订单状态机（v1.1 新增）

待支付 → 已支付 → 已发货（会员延期成功）；待支付 → 已关闭（15 分钟未支付）；已支付 → 退款中 → 已退款；已发货 → 退款中（7 天无理由/误扣申诉）→ 已退款（权益折算终止）。状态单向流转，禁止「已发货 → 已支付」回跳；回调与主动查询双通道保持一致，差异触发对账告警。

## 十一、权限与安全要求（含未成年人保护与数据合规专项 ★）

### 11.1 角色权限矩阵

| 功能 | 家长 | 学生 |
|------|------|------|
| 题库增删改查 | ✅ | ❌（不可见配置值） |
| DIY 配置 | ✅ | ❌ |
| 紧急解锁/远程收回 | ✅ | ❌ |
| 查看报告 | ✅（全量） | 仅本人简要版 |
| 答题与激励兑换 | ❌（可代为确认兑换） | ✅ |
| 设备绑定/解绑 | ✅ | ❌（发起需家长确认） |

### 11.2 未成年人保护专项（8 项）

1. **监护人同意**：学生账号必须由监护人注册绑定后才能使用；注册流程明示《儿童/未成年人个人信息保护规则》并取得授权勾选。
2. **数据最小化**：仅采集运维必需数据（年级、作答数据、设备指纹）；禁止采集通讯录、位置、短信等非必要权限。
3. **防沉迷友好**：本产品定位为「减少屏幕滥用」，激励设计禁止任何延长使用时长的诱导（奖励时长功能默认关闭，由家长开启）。
4. **内容安全**：题库内容先审后用；内置题库需内容授权与审核记录。
5. **无诱导设计**：无概率性奖励（抽奖/开箱）、无社交攀比排行、无信息流广告。
6. **夜间保护**：22:00–6:00 默认锁定（家长可配置），答题页夜间护眼模式。
7. **紧急通道**：锁定态紧急呼叫与家长联系永远可用（FR-17，安全底线）。
8. **申诉与退出**：家长可一键暂停全部管控（学生端显示「家长已暂停」），保障可逆性，避免产品沦为家庭矛盾激化工具。

### 11.3 数据合规专项（8 项）

1. **分类分级**：实名信息（高敏）加密存储；作答数据（中敏）；配置数据（内部）。
2. **PII 脱敏**：手机号展示一律 138****1234 形式；日志中禁止明文 PII。
3. **告知同意**：双端首次启动弹出版本化隐私政策，重大变更重新征求同意。
4. **用户权利**：提供数据查询、导出、更正、删除入口；注销账号后 15 个工作日内删除或匿名化全部数据。
5. **留存期限**：作答记录默认留存至账号注销后删除；绕过事件留存 90 天（安全目的，超期删除）。
6. **第三方共享**：内容审核服务（题目文本）需在隐私政策列明；禁止与广告商共享学生数据。
7. **安全措施**：传输加密、存储加密、接口鉴权、操作审计日志（家长敏感操作全部留痕）。
8. **安全事件响应**：数据泄露事件 24 小时内启动应急流程并按法规要求履行告知义务。

### 11.4 支付与广告安全专项（v1.1 新增）

1. **付费主体校验**：支付操作必须由家长账号在家长端完成，且家长已完成手机号 + 实名核验；学生端不渲染任何购买入口与价格信息。
2. **广告合规**：激励视频广告主行业白名单（禁止赌博、色情、高利贷、医疗功效类广告）；广告素材需过平台审核；学生账号数据禁止用于广告定向（与 11.3-6 一致）。
3. **未成年人消费防线**：家长设备上的支付需密码/生物验证；发现学生端出现支付路径的缺陷按最高优先级修复（安全缺陷，不走常规排期）。
4. **自动续费合规**：明示扣费规则、扣费前提醒、便捷取消（FR-29），符合《消费者权益保护法实施条例》对自动续费的要求（具体条款适用性由法务确认）。
5. **第三方登录数据最小化**（v1.2）：微信授权仅采集 openid/unionid 与基础昵称头像（用户可拒绝昵称头像授权，不影响使用）；禁止读取微信好友关系与朋友圈数据；解绑/注销时同步删除授权关系。
