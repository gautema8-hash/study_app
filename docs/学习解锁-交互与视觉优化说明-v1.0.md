# 「学习解锁」入口 / 身份切换 / 退出限制 / 全端视觉优化说明

> 日期：2026-11-05 ｜ 范围：app-frontend（全端页面）、app-backend（密码接口）、Android 原生守护
> 结论：**四项需求全部落地，功能与全量 E2E 回归通过 ✅**；真机 HOME 键受 HyperOS 系统授权限制，已给出完整的降级与一次性授权路径（见 §4）

## 一、需求逐条落地

| 需求 | 实现 |
|------|------|
| 左上角明确按钮入口 | 新增统一 `uiParentAccessButton`（`core/identity.dart`），出现在家长首页、孩子端 gate、答题页、结果页、激励中心、学生首页；原长按标题保留为辅助入口 |
| 长按操作的密码默认提示 + 设置/修改入口 | 统一「家长入口」底部面板：查询 `GET /api/auth/password/parent/status`，未设置时明确提示「尚未设置家长操作密码…请在下方创建 6 位数字密码」；面板内始终有「设置 / 修改操作密码」表单（已设置需原密码），身份选择页与家长首页另有直达按钮，杜绝「要求密码却没有入口」 |
| 顶部单选式身份切换 | 新增 `UiIdentitySwitcher`（SegmentedButton 单选），置于家长端与孩子端 AppBar 下方；**学生→家长、家长→学生均强制校验家长操作密码**；校验失败红色横幅 + 输入框描红 + **保持当前身份、不跳转**（真机已验证 403 场景） |
| 退出限制 | 返回键 `PopScope(canPop:false)` 保持；退出登录统一收敛到家长入口面板「验证通过后退出」，不再存在无密码直接退出 |
| HOME 键退出 | 原生 `onUserLeaveHint` 立即拉回 + `GuardService` 3 秒检查 + 切离提醒通知（点击即回）+ Flutter 生命周期上报 T-02 风控事件并重新裁决 + HOME 别名（默认桌面）与通知权限一次性系统授权入口。详见 §4 |
| 全端统一豪华视觉 | 新增 `core/ui.dart` 共享设计系统：深靛渐变品牌区、金铜点睛、圆角 30/24/14、单层柔和阴影、统一字体层级（31/20/15/14/13）、三态输入框、统一主/次按钮、状态横幅（info/error/success）、悬浮卡片；登录/身份选择/家长首页/孩子端 gate/答题/结果/激励中心/学生首页全部复用 |

## 二、服务端接口变更（app-backend）

| 接口 | 变更 |
|------|------|
| `GET /api/auth/password/parent/status` | **新增**，返回 `hasPassword`，供 UI 决定「设置」还是「修改」 |
| `POST /api/auth/password/parent` | 支持 `oldPassword`；**首次设置**允许任意登录态（避免孩子端死锁），**已设置后修改**必须家长身份 + 正确原密码，防止孩子自行改密码绕过切换校验 |
| `POST /api/auth/password/parent/verify` | 保持任意登录态可校验（孩子端切家长需要），错误返回 403，文案原样透传到面板 |

E2E 脚本 `auth_e2e.sh` / `control_e2e.sh` 已按状态查询适配（已设置时带旧密码），6 支 App E2E 全绿、`admin_e2e.sh` 39/39。

## 三、交互链路（真机验证）

1. 登录 → 身份选择页（品牌区 + 双身份卡 + 明确的「设置 / 修改家长操作密码」入口）→ 面板显示**未设置默认提示** → 创建 6 位密码 → 绿色成功横幅、按钮变「修改操作密码」；
2. 家长首页：左上角按钮、顶部单选切换、会员/DIY/密码三卡统一视觉；
3. 家长→学生：点「学生端」→ 密码面板「切换到「学生端」需验证」→ 错误密码 → **红色错误提示 + 家长端仍选中 + 无跳转** → 正确密码 → 验证通过 → 确认切换 → 孩子 gate（E-03 状态卡 + 顶部切换 + 左上入口）；
4. 学生→家长：点「家长端」→ 同样密码校验 → 切回家长首页，双向闭环成立；
5. DIY 滑块保存仍写入数据库（误触改成 72 后已通过 API 恢复 94，配置功能正常）。

## 四、HOME 键处理的真实边界（重要）

**代码层已做的四层防护**：
1. 原生 `MainActivity.onUserLeaveHint()`：按 HOME / 切应用立即 `moveTaskToFront` + `startActivity` 拉回；
2. `GuardService`：前台服务 3 秒周期检查，切离时拉回并发送「请回到学习解锁」常驻通知（点击即回，60 秒节流），Android 13+ 自动申请 `POST_NOTIFICATIONS`；
3. Flutter `WidgetsBindingObserver`：`paused/hidden` 静默上报 **T-02 风控事件**（服务端自动写家长告警），`resumed` 重新由 gate 裁决状态；
4. 动态 `KioskLauncher` HOME 别名（仅孩子设备启用）+ 家长入口面板两个系统授权入口：「系统守护授权（设为默认桌面）」「开启守护通知（切离提醒）」。

**小米 15 / HyperOS 实测结论（如实记录）**：
- T-02 风控上报 ✅（多次按 HOME 均入库）；
- 系统拒绝 `dpm set-device-owner`、`cmd package set-home-activity`，并拦截后台启动 Activity、把通知渠道默认设为 `importance=NONE` → **纯代码无法 100% 阻止按 HOME 回到系统桌面**；
- 因此产品采用诚实降级：未获系统授权时显示「提醒级 — 按 HOME 可切离，请家长完成一次授权」，同时记录风控事件、发切离提醒、回到前台重新裁决；家长通过面板完成「默认桌面 + 通知」两项一次性授权后，由系统层兜底（按 HOME 直接进入孩子端 / 通知可见可点回）。
- 不锁死、不虚假宣称全覆盖（与《孩子端强管控约束评审》D-2 一致）。
