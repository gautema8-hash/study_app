# 「学习解锁」包结构重构迁移说明

> 日期：2026-11-05 ｜ 目标：按 App 前端 / App 后端 / Web 前端 / Web 后端拆分为 4 个独立包，功能行为不变
> 结论：**迁移完成，双端构建与全量回归通过 ✅**

## 一、旧 → 新目录映射

| 旧 | 新 | 说明 |
|----|----|------|
| `app/` | `app-frontend/` | 整体 git mv，Flutter 业务代码、Android 原生守护、依赖声明与构建入口全部保留 |
| `backend/`（主体） | `app-backend/` | App 业务域（account/bank/quiz/control/risk/member/adreward/reward/common/config）独立成包 |
| `admin-web/` | `web-frontend/` | 整体 git mv，React + Vite 独立成包 |
| `backend/` 内 `opsbff/` + `config/Admin*` | `web-backend/` | Web 后台接口与 RBAC 拆出为独立 Spring Boot 服务 |
| `backend/mvnw`、`.mvn/` | 根 `mvnw`、`.mvn/`、`pom.xml` | Maven wrapper 上移；根 pom 仅 `packaging=pom` + modules 聚合，**无业务代码** |

## 二、四个包的职责与边界

```
study/
├── app-frontend/   # App 前端：Flutter（孩子端/家长端）  pubspec.yaml + android/ + ios/
│                     API_BASE → http://127.0.0.1:8080（app-backend）
├── app-backend/    # App 后端：Spring Boot 独立服务 8080  pom.xml + src/main/{java,resources}
│                     账号/题库/判分/会话管控/激励/资金/风控；含 Redis 依赖
├── web-frontend/   # Web 前端：React + Vite 3100        package.json + vite.config.ts
│                     /api 代理 → http://localhost:8081（web-backend）
└── web-backend/    # Web 后端：Spring Boot 独立服务 8081 pom.xml + src/main/{java,resources}
                      OpsController / AdminAuthInterceptor / AdminWebConfig /
                      SecurityConfig / WebTokenService / WebAdminApplication
根目录：pom.xml（仅聚合）、mvnw（wrapper）、sql/（共享数据库迁移）、
        scripts/（测试资产）、docs/（文档）、deploy/（部署脚本）
```

**依赖边界（已用 grep 验证零残留）**：
- `web-backend` **不 import 任何 app-backend 的 Java 类**：自带 `WebTokenService`（同 HS256 算法、同 `JWT_SECRET` 环境变量，token 自洽签发与校验）与独立 `SecurityConfig`；
- `app-backend` 不含任何 web/opsbff 引用；
- 两服务通过**共享 MySQL 数据源**做运营读模型（数据层共享，代码/配置各自独立）；`web-backend` 不依赖 Redis；
- `web-frontend` 只感知 8081，`app-frontend` 只感知 8080，两端互不感知。

## 五、运行速查

```bash
# 一次编译两个后端包
./mvnw clean compile
# 分别启动（Windows 沙箱需 SERVER__PORT 覆盖环境变量）
SERVER__PORT=8080 ./mvnw -f app-backend/pom.xml spring-boot:run
SERVER__PORT=8081 ./mvnw -f web-backend/pom.xml spring-boot:run
# 前端
cd web-frontend && npm run dev                        # 3100 → 8081
cd app-frontend && flutter build apk --debug --dart-define=API_BASE=http://127.0.0.1:8080
# 全量回归
bash scripts/admin_e2e.sh; PHONE=<新号> WEB_BASE=http://127.0.0.1:8081 bash scripts/review_e2e.sh
```

## 六、说明

- `sql/`、`scripts/`、`docs/`、`deploy/` 是跨端基础设施与测试资产，不属于任何一端的业务包，未并入四个包内。
- 历史 PRD/架构文档保留迁移前的目录描述，以本说明的映射表为准。
- 双后端共享同一 MySQL 实例与库；如需彻底的数据边界，后续可按「App 业务库 + 运营只读库」再演进。
